WOOP Iron Deficiency Test landing page

Files
- index.html
- styles.css
- assets/ (all image and SVG assets)

How to use
1. Open index.html in a browser.
2. In index.html, replace:
   const CLIENT_URL = "https://example.com";
   with the actual client website URL.
3. Upload the whole folder to your hosting provider.

Notes
- Mobile-first responsive design.
- The page contains two CTAs, both connected to the same client URL.
- The support/email block from the previous concept has intentionally been removed.
- Logo/family image crops are taken from the approved concept image supplied in this conversation.
- The supporting icons are included as editable SVG files.
